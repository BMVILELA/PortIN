# Liga das Portabilidades

App das lojas NOS para registar, por dia, Voz Móvel e portabilidades, com ranking e Backoffice.

- `index.html`: a app completa (lojas, ranking e Backoffice), publicada com GitHub Pages.
- Os dados ficam no Supabase. O ficheiro SQL de configuração não está neste repositório porque contém a password do Backoffice.

## Configurar
No início do script de `index.html`, preencher `SUPABASE_URL` e `SUPABASE_KEY` (chave pública "anon"/"publishable") com os dados do projeto Supabase.
